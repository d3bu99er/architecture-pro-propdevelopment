# Требования к интеграции с устройствами умного дома

## 1. Требования к безопасности

- Передача данных должна осуществляться исключительно по защищённому протоколу HTTPS
- Персональные данные шифруются на стороне клиента (мобильного приложения) до передачи на сервер
- Сервер обрабатывает данные только в зашифрованном виде; биометрическая информация не хранится в открытом виде ни на одном из уровней системы
- Хранилища данных для различных типов устройств (шлагбаумы и домофоны) логически и/или физически изолированы друг от друга

---

## 2. Аутентификация и авторизация

- Процесс аутентификации пользователей реализован через внешний сервис `auth-service-int`
- Для мобильного приложения:
  - доступ к функциям домофона осуществляется через REST API с использованием JWT-токена пользователя
  - доступ к функциям управления шлагбаумом также реализован через REST API с использованием JWT-токена

- Для взаимодействия устройств с системой:
  - домофоны проходят авторизацию с использованием уникального API-ключа, назначенного каждому устройству
  - шлагбаумы авторизуются аналогичным образом — через индивидуальный API-ключ

- Механизмы автоматического распознавания:
  - для домофонов — идентификация собственника
  - для шлагбаумов — идентификация транспортного средства
  реализуются через доверенное взаимодействие устройства и backend-сервиса с использованием API-ключей

---

## 3. Взаимодействие внутренних систем и внешних платформ

- Все взаимодействия между системами выполняются с использованием защищённого соединения (SSL/TLS)
- Любые интеграционные вызовы допускаются только при наличии валидного токена авторизации
- Токены авторизации имеют ограниченный срок жизни (TTL) и подлежат регулярному обновлению
